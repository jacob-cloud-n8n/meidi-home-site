# 美地案例 PDF 匯入 Skill 規劃

本文件記錄「PDF 案例資料轉成網站案例」的固定流程。等本次版型確認採用後，可依此建立 Codex 專用 Skill。

## 目標

將客戶提供的服務案例 PDF 轉成網站可展示、可維護、較不容易被盜用的案例內容。

Skill 不應直接把原始 PDF 上線，而是產出待審核版本：

- 壓縮後案例圖片
- 美地浮水印
- 案例專案資料草稿
- 案例空間資料草稿
- 後台欄位建議
- 前台預覽
- 上線前檢查清單

## 標準流程

1. 讀取 PDF 頁數、頁面尺寸與文字。
2. 判斷封面、亂源分析、解決方案、空間成果、物品地圖、結尾頁。
3. 移除或避開不適合公開的頁面，例如含姓名、電話、地址或內部提報資料的頁面。
4. 將可公開頁面轉成 WebP 或 JPG，限制寬度與品質。
5. 在圖片加上「美地居家收納｜案例預覽」浮水印。
6. 產生案例 slug，例如 `liu-home-storage`。
7. 產生 `案例專案` 草稿欄位。
8. 產生多筆 `案例空間` 草稿欄位。
9. 寫入網站素材資料夾，路徑格式為 `/assets/cases/<slug>/`。
10. 更新前台預覽或建立匯入資料。
11. 執行本機建置檢查。
12. 等人工確認授權、隱私、文案與圖片後，再發布。

## 人工確認項目

- 是否取得客戶同意公開。
- 是否可公開整份案例，或只能公開部分空間。
- 圖片是否露出姓名、地址、文件、孩子臉部或可識別私人物品。
- 文案是否過度描述客戶問題。
- 是否需要改用更中性的案例名稱。
- 是否正式改成 `已授權`。

## 後台資料欄位

### 案例專案

- `名稱`
- `類型=案例專案`
- `Slug`
- `分類`
- `摘要`
- `封面圖`
- `亂源分析`
- `解決方案`
- `授權狀態`
- `排序`
- `啟用`

### 案例空間

- `名稱`
- `類型=案例空間`
- `所屬案例` 或 `案例Slug`
- `空間名稱`
- `文字內容`
- `案例圖片`
- `排序`
- `啟用`

## 本次示範案例

- PDF：`客廳、玄關、更衣.pdf`
- 內建 slug：`liu-home-storage`
- 素材位置：`public/assets/cases/liu-home-storage/`
- 說明：原始 PDF 不進入公開資料夾，只保留壓縮與浮水印後的圖片。

## 未來 Skill 輸出

每次提供 PDF 後，Skill 應輸出：

- 案例圖片資料夾
- 後台欄位草稿表
- 隱私檢查結果
- 前台預覽連結
- 建置驗證結果

發布仍需由人工確認後執行。
